# Heart Disease Prediction using Machine Learning

## Objective
To build a machine learning model that predicts the presence of heart disease using patient medical attributes.

## Dataset
UCI Heart Disease Dataset

## Steps Followed
- Data loading and exploration
- Target variable binarization
- Categorical encoding using one-hot encoding
- Handling missing values
- Train-test split
- Logistic Regression model training
- Model evaluation using accuracy, classification report, and confusion matrix

## Model Used
- Logistic Regression

## Results
- Accuracy: ~78%
- Confusion matrix shows good detection of heart disease cases

## Tools & Libraries
- Python
- Pandas
- NumPy
- Scikit-learn
- Matplotlib
- Seaborn
